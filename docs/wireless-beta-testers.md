# Headswap：无线模式（beta）— 测试者指南

需要一台在车机 CarLife 里有**无线连接**选项（Wi-Fi / “WLAN” / “无线 CarLife”）的车。如果车机 CarLife 菜单里只有 USB，无线不会工作，不需要测试。

Beta 是独立的 APK。它覆盖安装到普通 Headswap 之上，设置会保留。有线模式照旧工作：插上数据线时 USB 优先。

## 要做什么

1. 安装 beta APK。
2. 在手机上开启**热点**。如果能选频段，选 5 GHz。如果设置里有热点自动关闭，关掉它。
3. 车机：让它连接手机热点（在车机 Wi-Fi 设置里找手机的网络并输密码）。不是所有车机都有这个选项——如果没有，在报告里写明。
4. 在车机上打开 CarLife。如果 CarLife 里有连接类型选择，选无线（Wi-Fi）。
5. 在 Headswap 中：设置 → “无线” → “通过 Wi-Fi 等待汽车”。在 Android 17 上允许“附近设备”访问权限。
6. 等 2–3 分钟。如果车机屏幕上出现了 Android Auto——开 10–15 分钟：触摸、音乐、导航、方向盘按键语音。
7. 无论成功与否——点“发送无线报告”，并把文件连同下方填好的模板一起发来。

**如果车机自己通过蓝牙和 Wi-Fi Direct 连接手机（例如 Mazda）：** 不需要手机热点。打开手机的蓝牙和 Wi-Fi，手机需要与车配对。点“通过 Wi-Fi 等待汽车”，允许“附近设备”（旧版 Android 上允许定位）。然后在车机 CarLife 里选择无线连接。报告页面上的“Bluetooth carlife”一行可以看到进行到哪一步：“车机已连接”、“进入群组中”、“手机已在车机组中”、“已给车机 IP，等待车机 TCP”。

停止模式：同处的“停止”按钮。

## 报告模板

```
车辆：品牌、型号、年份、市场（中国 / 其他）
车机：名称和软件版本，如果在菜单里能看到
车机如何连上 Wi-Fi：（连手机热点 / 车机自己开 Wi-Fi / 没找到选项）
车机 CarLife 菜单里的连接类型（按原样照抄）：
在点 Headswap 按钮前车机是否已打开 CarLife 页签：是 / 否
手机：型号、Android / 系统版本
热点频段：2.4 / 5 GHz / 不知道
结果：AA 是否出现在车机屏幕上——是 / 否；如果没有，Headswap 屏幕上显示什么（“无线：…”一行）
能用的功能：触摸 / 音乐 / 导航 / 语音 / 通话
断连：有没有，多少分钟后
发热和充电：开始时和结束时的 %，手机有没有在充电
附件报告（zip）：有
```

## 报告里有什么

应用日志、`wireless.log` 文件（无线连接各步骤）和手机信息。热点密码和名称不会进报告。会进的是：手机型号、车机名称、热点局域网内的地址。
